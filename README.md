# Visualización de Datos

Un proyecto de análisis y visualización de datos usando Python, Pandas y Plotly.

## Requisitos

- Python 3.8+
- Pandas
- Plotly
- Jupyter

## Instalación

1. Crea un entorno virtual:
```bash
python -m venv venv
source venv/bin/activate  # En Windows: venv\Scripts\activate
```

2. Instala las dependencias:
```bash
pip install -r requirements.txt
```

3. Inicia Jupyter Notebook:
```bash
jupyter notebook
```

## Estructura del Proyecto

- `analysis.ipynb` - Notebook principal para análisis y visualizaciones
- `requirements.txt` - Dependencias del proyecto
- `README.md` - Este archivo

## Uso

Abre `analysis.ipynb` en Jupyter Notebook y comienza a explorar los datos.
